# 📦 Scribloom CHANGELOG

このドキュメントは Scribloom のバージョンごとの機能変更履歴を記録するものです。

---

## [v0.1.0] - 2025-07-11

初期公開バージョン。創作ループ（お題提示 → 執筆 → 保存 → 履歴表示）を最低限の構成で達成。

### ✨ 新機能

- 日替わりお題生成機能
  - 日付に基づいた一貫性と変化性を両立
  - テーマ、ジャンル、舞台を組み合わせて提示

- Markdown 対応の執筆エリア
  - 入力とプレビューの両対応
  - リアルタイム文字数カウント

- 投稿の保存機能
  - Pydantic による Post モデル管理
  - JSON 形式で日付をキーにして保存

- 履歴表示機能
  - 保存された投稿を日付降順で展開
  - お題内容と文字数付きの見出しで整理

### 📘 ドキュメント整備

- `structure.md`: ディレクトリ構成と責務説明
- `dataflow.md`: アプリの処理フローとデータ流れを図示
- `design.md`: 設計思想、技術選定、MVPの定義を記述

### 🧪 テストカバレッジ

- `generate_daily_prompt()` の再現性・変化性を検証
- JSON 保存・読み込み処理の正常系・異常系を網羅
- 各テストファイルに docstring を付与し意図を明記
