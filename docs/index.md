# 📘 Scribloom Docs

このページでは、Scribloom の内部構造や設計思想、処理の流れなどを把握するための補足ドキュメントを案内します。  
プロジェクトに興味を持った方が、意図と仕組みを理解できるよう構成しています。

---

## 🗂 ドキュメント一覧

| ドキュメント            | 内容概要                                                                       |
|--------------------------|--------------------------------------------------------------------------------|
| [structure.md](structure.md)     | ディレクトリ構成とモジュールごとの責務を整理                              |
| [dataflow.md](dataflow.md)       | アプリの処理フローとデータの流れを図式化                                  |
| [design.md](design.md)           | 設計思想、技術選定、ユーザー体験の意図を明文化                            |
| [changelog.md](changelog.md)     | バージョンごとの機能到達点と今後の展望                                  |
| [CONTRIBUTING.md](../CONTRIBUTING.md) | 外部からの貢献方法、IssueやPRの運用ルールなど（プロジェクトルートに配置） |

---

## 🧭 推奨読書順

1. `structure.md`: ディレクトリごとの役割をざっくり把握
2. `design.md`: なぜこの構成なのかを思想で理解
3. `dataflow.md`: 実際のデータの流れを図解で確認
4. `changelog.md`: 現在の機能と今後の構想を把握
5. `CONTRIBUTING.md`: コラボレーションへの案内

---

## 🛠 編集・提案について

このドキュメントは随時更新しています。  
もし「もっとこうすれば分かりやすい」「図解があると良い」といった提案があれば、
